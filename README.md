# LRO_eco_forecasting

Project aimed at forecasting oxygen data at different sites throughout the Logan River Observatory.

Code:
Cleaning Data - Downloading data from website and cleaning it
Exploring Data - Graphing data 
Weekly ARIMA - fitting time series models 

Data:
data created from "Cleaning Data"
sub folder "model fits" - includes the models fitted from "Weekly ARIMA"

Other:
Includes CSV files, exploring with the ARIMA models originally with their models.
